# Sri Rudram chant practice

A small, private learning page for one learner. It plays the late K. Suresh's chanting from his YouTube channel "The Ghanapati" through YouTube's own player, records the learner on her device, and checks the rise and fall of each syllable against the svara marks. The learner's voice is analysed in the browser and never uploaded.

- `index.html`: the practice app
- `tap.html`: marking where each line starts in the videos
- `mic.html`: device check

Text: sanskritdocuments.org, *rudraprashnaH svara sahitam* and *chamakaprashnaH (sasvaraH)*, by Rajagopal Iyer and Rekha Venkatesh (https://sanskritdocuments.org/doc_shiva/rudra.html). Meanings were written for this course. Not for redistribution.
